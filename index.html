📋 Gmail Setup Instructions
  1. Go to your Google Account → Security → 2-Step Verification (must be ON)
  2. Search for "App passwords" in your Google Account settings
  3. Generate an App Password for "Mail" → "Windows Computer"
  4. Copy the 16-character password and paste it below
→ Open Google App Passwords ↗
📋 Outlook / Hotmail Setup Instructions
  1. Sign in to account.microsoft.com → Security → Advanced Security Options
  2. Enable "Two-step verification" if not already on
  3. Under "App passwords" click Create a new app password
  4. Copy the password shown and paste it below
→ Open Microsoft Security Settings ↗
📋 Yahoo Mail Setup Instructions
  1. Go to Yahoo Account Security settings
  2. Turn on "Two-step verification"
  3. Click "Generate app password" → select "Other app"
  4. Name it "LeadForge" and copy the generated password
→ Open Yahoo Account Security ↗
